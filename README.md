## ✨ Особенности

### 🎨 Богатый набор инструментов
| Инструмент | Описание | Иконка |
|------------|----------|--------|
| **Кисть** | Свободное рисование с настраиваемой толщиной | 🖌️ |
| **Ластик** | Удаление частей рисунка | 🧽 |
| **Заливка** | Закрашивание замкнутых областей | 🎨 |
| **Пипетка** | Выбор цвета с холста | 💉 |

### 👥 Совместная работа
- **Реальное время** — мгновенная синхронизация между участниками
- **Автосохранение** — не теряйте прогресс при перезагрузке
- **Частные комнаты** — рисуйте только с друзьями

### 📁 Управление проектами
- Загрузка изображений на холст
- Экспорт в PNG
- Отмена/повтор действий (Ctrl+Z / Ctrl+Y)
- Полная очистка холста

## 🚀 Быстрый старт

### Предварительные требования

- [Node.js](https://nodejs.org/) (версии 14 или выше)
- npm или yarn

### Установка

1. **Клонируйте репозиторий**
```bash
git clone https://github.com/rold174/js_ris.git
cd js_ris
```
2. **Установите зависимости**
```bash
npm install
```
3. **Запустите сервер разработки**
```bash
npm run dev
```
4. **Откройте приложение**
   <div>
   Откройте браузер и перейдите по адресу http://localhost:3000
   </div>
